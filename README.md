# 🎰 Retro Casino PSP — Telegram Mini App & Web Game

Пиксельная 2D игра в формате казино в стиле консоли Sony PSP с аутентичным ретро-дизайном, виртуальным дилером, комнатами в стиле КПД, таблицей лидеров и магазином мемных образов (Михаил Зубенко, Иван Золо, Саша Белый и др.).

---

## 🌟 Основные возможности

### 1. Регистрация и система персонажей
- Выбор внешности при первом входе: пол (парень / девушка), тон кожи (от светлых до темнокожих), прически и цвета волос.
- Ввод персонального никнейма.
- **Стартовый баланс: 300 фишек** сразу при создании аккаунта.
- Кнопка «Дневной бонус» (+100 фишек) и «Подгон от казино» (+50 фишек, если баланс опустился ниже 10).

### 2. Игровые режимы с виртуальным дилером
- ♠️ **Блэкджек (21 очко)**:
  - Автоматическая раздача карт виртуальным дилером с аутентичными правилами казино.
  - Натуральный блэкджек платит 3 к 2. Дилер берет до 17.
  - Действия: «Еще» (Hit), «Хватит» (Stand), «Удвоить» (Double Down).
  - Анимированные пиксельные карты и фишки со звуковыми эффектами (Web Audio 8-bit).
- 🎲 **Европейская рулетка**:
  - Анимированное вращающееся колесо на Canvas с реалистичным шариком и звуками тиков.
  - Поле для ставок: числа от 0 до 36 (выплата 35:1), Красное / Черное, Чет / Нечет, 1-18 / 19-36, Дюжины и Колонки (2:1).
  - История последних выпавших чисел.

### 3. Комнаты и лобби в стиле игры КПД
- Список открытых столов с информацией о минимальной ставке, количестве игроков и их пиксельных аватарах.
- Возможность создать собственный стол (название, режим, мин. ставка, количество мест).
- Внутри игровой комнаты: отображение сидящих за столом игроков, интерактивный чат со столом и быстрые мемные фразы («Шумим, братец!», «На фарт!», «Банк!»).

### 4. Гардероб и Магазин мемных образов
- **Михаил Зубенко** («Вор в законе, шумим братец!» — кепка-восьмиклинка, полосатый пиджак и четки).
- **Иван Золо** (легендарное красное поло, проводные наушники с микрофоном).
- **Саша Белый / Бригада** (кожаный плащ 90-х и золотая печатка).
- **Арабский Шейх** (белоснежная куфия, золото и часы).
- **PSP Ретро-Геймер** (фиолетовый худи и консоль PSP в руках).
- **Киберпанк Неон**, Золотая корона, очки Deal With It, золотая цепь $, сигара и VIP скины фишек.
- Живая примерочная: аватар игрока сразу меняется в реальном времени во всех элементах интерфейса (в лобби, за столом, в шапке и таблице лидеров).

### 5. Таблица лидеров (Лидерборд)
- Рейтинг самых богатых каперов по количеству фишек.
- Отображение побед, медалей топ-3 и персональных пиксельных аватаров.

### 6. Адаптивность и звук
- Оптимизировано как под мобильные устройства (Telegram Mini App), так и под ПК: кнопки не загораживают экран, управление эргономично.
- Встроенный синтезатор ретро 8-bit звуков (Web Audio API, без тяжелых внешних файлов).

## 🚀 Как запустить проект

### 1. Локальный запуск (быстрый старт):
Просто запустите встроенный сервер через Python:
```bash
py bot.py --serve
```
И откройте в браузере: `http://localhost:8000`

Либо откройте файл `index.html` напрямую в любом современном браузере.

### 2. Запуск в Telegram Mini App:
1. Загрузите файлы на хостинг с HTTPS (например, GitHub Pages, Vercel, Netlify или Render).
2. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather), получите `BOT_TOKEN`.
3. В @BotFather введите `/newapp`, выберите созданного бота и укажите URL вашего развернутого сайта.
4. В файле `bot.py` укажите ваш токен и URL WebApp:
   ```python
   BOT_TOKEN = "ВАШ_ТОКЕН_БОТА"
   WEBAPP_URL = "https://ваш-домен.io"
   ```
5. Установите зависимости и запустите бота:
   ```bash
   pip install -r requirements.txt
   py bot.py
   ```
